# Atividade Somativa 2

Aplicação React desenvolvida para a Atividade Somativa 2.

## Tecnologias

- React
- React Router DOM
- Firebase Authentication
- Firebase Firestore

## Instalação

```bash
npm install
```

## Configuração

Preencha `src/services/firebase.js` com a configuração do aplicativo Web criado no Firebase Console.

No Firebase Authentication, habilite o provedor E-mail/senha.

Crie o Firestore Database.

## Executar

```bash
npm run dev
```

## Build

```bash
npm run build
```

Não incluir a pasta `node_modules` na entrega ZIP.
